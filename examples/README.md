# 利用事例(索引)

汎用の一式(`00-overview/`〜`05-records-kpi/`)を、架空の組織と具体的な製品に当てはめた利用事例を置く。
事例は汎用の一式の **適用例** であり、汎用の一式の設計根拠にはしない([ADR-014](../docs/decisions/ADR-014-examples.md))。

| 事例 | 想定組織 | 主な製品構成 |
|---|---|---|
| [`smb-m365/`](smb-m365/README.md) | 従業員160名の部品製造業(架空のA社)。情報システム担当2名 | Microsoft 365 Business Premium、Microsoft Sentinel、FortiGate、国内事業者のMDR |

## 事例を読むときの注意

- 組織・人物・数値はすべて架空である。実在の組織の構成を示すものではない。
- 製品の機能・ライセンス・提供条件は、各事例の文書に記載した確認日の時点の情報である。製品は頻繁に変わるため、
  採用する前に各社の最新の資料で確認すること。
- 事例は汎用の一式の文書を書き換えない。汎用の文書の規則を、事例の組織と製品でどう実現するか(差分)だけを書く。

## 事例を追加するには

1. `examples/<slug>/` を作り、`README.md`(索引)を置く。
2. 文書IDの分類コードは事例ごとに決め、[OV-003](../00-overview/00-03-document-conventions.md) 第1章の表に追加する。
3. 本索引に1行追加し、[`CHANGELOG.md`](../CHANGELOG.md) に追記する。
