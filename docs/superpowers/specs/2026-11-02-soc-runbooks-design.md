# 設計書: SOC運用手順書群(サブプロジェクト4)

## 1. 目的・スコープ

本文書は、SOCが代表的な検知シナリオに対してどう対応するかを定めるRunbook群の構成を定義する。
NIST CSF 2.0の **Detect** 機能に対応する。実文書は [`03-soc-runbooks/`](../../../03-soc-runbooks/)
配下に展開する。

### スコープ外

- CSIRT発動後の対応(フォレンジック・復旧等) → サブプロジェクト5
- 記録フォーマットの正式項目定義 → サブプロジェクト6

## 2. 対象シナリオ

オンプレミス・クラウド双方の資産を持つ前提のもと、以下7シナリオをサンプルとして用意する。

1. 異常ログイン検知(不正アクセスの疑い)
2. フィッシング検知
3. マルウェア検知
4. ランサムウェア前兆検知
5. 内部不正の疑い
6. 権限昇格の検知
7. 外部公開クラウド設定ミス(クラウド誤設定による露出)

## 3. 共通テンプレート構成

各Runbookは以下の構成に統一する。

1. **トリガー条件**: どのアラート・条件で本Runbookが発動するか
2. **誤検知パターン(除外条件)**: よくある誤検知とその判別方法
3. **Tier別アクション**: Tier1/2/3がそれぞれ何を行うか([GOV-001](../../../01-governance/01-01-organization-structure.md)のTier構造に対応)
4. **Agentic AIの分担**: [AI-002](../../../02-agentic-ai/02-02-authority-levels.md)の権限レベル(Lv1/2/3)を、このシナリオの具体的操作に当てはめる
5. **エスカレーション条件**: [GOV-002](../../../01-governance/01-02-severity-and-escalation.md)の重大度分類への当てはめ、CSIRT発動基準
6. **記録**: 記録すべき情報の種類([`05-records-kpi/`](../../../05-records-kpi/)で正式フォーマットを定める)

ベンダー非依存の原則上、具体的なSIEM製品のクエリ構文は記述せず、「どのようなログ・アラート種別を
参照するか」という抽象度で記述する。

## 4. NIST CSF 2.0との対応

| CSF 2.0機能 | 対応内容 |
|---|---|
| Detect | 7シナリオのトリガー条件・誤検知判別・Tier別アクション |
| Respond(一部) | エスカレーション条件によるCSIRTへの橋渡し |
