# 設計書: 記録フォーマット・KPI・NIST CSF 2.0成熟度評価シート(サブプロジェクト6)

## 1. 目的・スコープ

本文書は、これまでの5サブプロジェクトで「正式フォーマットはサブプロジェクト6で定める」として
参照していたインシデント記録・AI判断ログを確定し、KPI・NIST CSF 2.0成熟度評価のフォーマットを
定義する。実文書は [`05-records-kpi/`](../../../05-records-kpi/) 配下に展開する。

## 2. 文書構成

| # | 文書 | 内容 |
|---|---|---|
| 1 | インシデント記録フォーマット | インシデントID・検知時刻・重大度・対象アセット・関連Runbook・対応Tier・エスカレーション・外部報告・クローズ時刻・事後レビュー実施有無 |
| 2 | AI判断ログフォーマット | [AI-003](../../../02-agentic-ai/02-03-decision-logging.md)の項目を実記入テンプレートとして確定 |
| 3 | KPIシート | MTTD・MTTR・誤検知率・エスカレーション件数の定義・算出方法・収集頻度 |
| 4 | NIST CSF 2.0成熟度評価シート | NIST標準の4段階Implementation Tier(Tier1〜4)による6機能の評価、根拠文書の紐づけ |

## 3. 各文書の要点

### 3.1 インシデント記録フォーマット

Markdownテーブル形式のテンプレートとする。実際の運用では、各組織のチケットシステム・SIEMの
インシデント管理機能にこの項目を転用することを前提とする。

### 3.2 AI判断ログフォーマット

[AI-003](../../../02-agentic-ai/02-03-decision-logging.md)で定義した8項目
(判定時刻・対象アセット・トリガー・実行エージェント・判定根拠・権限レベル・実行結果・レビュー結果)
を、そのまま記入用テンプレートとして確定する。

### 3.3 KPIシート

| 指標 | 定義 | 算出方法 |
|---|---|---|
| MTTD(平均検知時間) | 攻撃発生から検知までの平均時間 | Σ(検知時刻-推定発生時刻)/件数 |
| MTTR(平均対応時間) | 検知からクローズまでの平均時間 | Σ(クローズ時刻-検知時刻)/件数 |
| 誤検知率 | 全アラートに対する誤検知の割合 | 誤検知件数/全アラート件数 |
| エスカレーション件数 | SOCからCSIRTへのエスカレーション件数(重大度別) | 重大度別の件数集計 |

収集頻度は月次とし、四半期ごとにSOCマネージャーが傾向をレビューする
([AI-004](../../../02-agentic-ai/02-04-audit-and-kill-switch.md)の四半期レビューと合わせて実施)。

### 3.4 NIST CSF 2.0成熟度評価シート

NIST CSF 2.0標準のImplementation Tierを採用する。

| Tier | 定義 |
|---|---|
| Tier 1: Partial | 個別の取り組みがあるが、組織的な方針として確立されていない |
| Tier 2: Risk Informed | リスクに基づく方針があるが、組織全体への適用が不十分 |
| Tier 3: Repeatable | 組織全体で方針が確立され、継続的に実施されている |
| Tier 4: Adaptive | 過去の経験・脅威動向に基づき、継続的に方針を改善している |

6機能(Govern/Identify/Protect/Detect/Respond/Recover)ごとに現在のTierを評価し、根拠となる
本リポジトリの文書(GOV/AI/SOC/CSIRT各ID)を紐づける表を作成する。

## 4. NIST CSF 2.0との対応

本サブプロジェクト自体が、NIST CSF 2.0の全機能の評価を担う位置づけである。
