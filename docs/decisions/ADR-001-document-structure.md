# ADR-001: 文書体系

- ステータス: 採用
- 決定日: 2026-11-01

## 背景

設計書・手順書・記録フォーマットを一式で公開し、利用者が自組織に合わせて修正して使う前提である。

## 決定

- ディレクトリは番号付き(`00-overview/`〜`05-records-kpi/`)とし、読む順を固定する。
- 文書はMarkdown、図はMermaidで、文書内に直接書く。
- 言語は日本語のみとする。
- ライセンスはCC BY 4.0とする。
- 共通ヘッダーは文書ID・バージョン・改訂日の3項目だけとする。
- 調整可能な数値はパラメータID(`P-xx`)で管理する([OV-004](../../00-overview/00-04-customization-points.md))。

詳細な規約は [OV-003](../../00-overview/00-03-document-conventions.md) に置く。

## 理由

- 番号付きのディレクトリは、GitHub上で読む順に並び、初めての人でも迷わない。
- Markdown・Mermaidはテキストで差分を管理でき、利用者が修正しやすい。
- ヘッダーを最小にすると、文書の追加・修正の手間が減る。CSF対応などのメタ情報は1箇所に集める(ADR-002)。
- CC BY 4.0は、出典の表示だけで改変・再配布・商用利用を認めるため、社内規程の土台として使いやすい。

## 検討した代替案

| 案 | 採らなかった理由 |
|---|---|
| 意味別のディレクトリ(番号なし) | 読む順がREADMEを見ないと分からない |
| SOC・CSIRT別に大きく分ける | 組織・AI・記録などの共通部分の置き場所が曖昧になる |
| 日英併記 | 作成・保守の手間が倍以上になる |
| ヘッダーに承認者・CSF対応を含める | 文書ごとに記入する手間が増え、内容がずれやすい |
| MIT License / CC0 | MITは文書には一般的でない。CC0は出典の表示を求められない |

## 変更するときの影響範囲

- ディレクトリ名・文書IDを変える場合: 全文書のリンク、[OV-003](../../00-overview/00-03-document-conventions.md)、README
- 英語版を加える場合: 文書ごとに対応する英語版を置くディレクトリの規約を [OV-003](../../00-overview/00-03-document-conventions.md) に追加する
