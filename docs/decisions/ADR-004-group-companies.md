# ADR-004: 構成会社との関係

- ステータス: 採用
- 決定日: 2026-11-01(外部報告の主体は2026-11-02に決定)

## 背景

構成会社は100社あり、規模も業種も異なる。システム子会社のSOC・CSIRTが、構成会社とどう連携するかを決める必要がある。

## 決定

- 各構成会社にセキュリティのPoC(兼任可)を置き、SOCとの連絡・資産情報の登録・現場での協力の窓口とする。
- 外部報告(規制当局・本人・取引先への報告)の主体は各構成会社とし、構成会社責任者が最終承認する。
  システム子会社は判定材料と下書きを作り、グループCISOはグループ横断の統制を担う。

## 理由

- 100社に個別に連絡先を探す運用は、事案のたびに時間がかかる。窓口を決めておくと初動が速くなる。
- 個人情報保護法などの報告義務は法人ごとに課される。グループCISOが承認して報告する形は、法的な責任の所在と合わない。

## 検討した代替案

| 案 | 採らなかった理由 |
|---|---|
| 構成会社に窓口を置かず、システム子会社が各社のIT部門に直接連絡する | 窓口が事案ごとに変わり、初動が遅れる |
| 規模に応じて体制を変える | 運用が複雑になる。必要なら、小規模な構成会社のPoCを親会社や近い構成会社と兼ねる形で対応できる |
| グループCISOが外部報告を一元的に承認する | 法人ごとの報告義務と合わない。各社との事前の合意が必要になる |
