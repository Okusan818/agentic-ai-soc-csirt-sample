# ADR-007: オーケストレーターと専門エージェントの構成

- ステータス: 採用(調査・分析エージェントの構成は [ADR-013](ADR-013-evidence-grounded-investigation.md) で拡張)
- 決定日: 2026-11-02

## 背景

Agentic AIに一次評価から封じ込めまでを担わせるにあたり、エージェントの構成を決める必要がある。

## 決定

- オーケストレーターが全体を制御し、トリアージ・調査分析・封じ込め・報告ドラフトの専門エージェントにタスクを振り分ける。
- 権限レベルの判定はオーケストレーターが規則に従って行い、エージェント自身には判定させない。
- 読み取り系のエージェントと、書き込み(措置)系のエージェントを分ける。

詳細は [AI-001](../../02-agentic-ai/02-01-architecture.md)。

## 理由

- エージェントごとにツール権限を絞れるため、1つのエージェントが攻撃や誤判定で暴走しても、影響範囲が限られる。
- 調査対象のデータには攻撃者が仕込んだ指示が含まれうる([AI-005](../../02-agentic-ai/02-05-ai-specific-threats.md))。
  措置の実行可否を規則で判定することで、エージェントの出力だけで措置が決まらないようにする。

## 検討した代替案

| 案 | 採らなかった理由 |
|---|---|
| 単一のエージェントが一連の作業を担う | 構成は簡単だが、権限を細かく分けられない |

## 変更するときの影響範囲

- 調査・分析エージェント群の内訳を変える場合: [ADR-013](ADR-013-evidence-grounded-investigation.md) の影響範囲を参照
- エージェントの分割を変える場合: [AI-001](../../02-agentic-ai/02-01-architecture.md) の表、[GOV-001](../../01-governance/01-01-organization-structure.md) 第2章の分担、各Runbookの「実行主体」
