# ADR-006: 外部報告は判定を自動、発信を人間の承認とする

- ステータス: 採用
- 決定日: 2026-11-01

## 背景

外部報告には法令・契約上の期限がある。判定を人が一から行うと遅れやすいが、誤った報告は信用を大きく損なう。

## 決定

- 外部報告が必要かどうかは、法務・広報と事前に合意したルールで自動判定する。
- 実際の報告・通知は、構成会社責任者の承認を経て人間が行う。AIは下書きまでを担い、送信しない。
- グループ内の報告(グループCISOへの社内報告)は、外部報告の判定とは別に、Critical・Highで必ず行う。

詳細は [GOV-003](../../01-governance/01-03-external-reporting-flow.md)。

## 理由

- ルールで判定すると、報告漏れと判断の遅れを防げる。
- 誤った通報は取り消しが難しく、法的な責任も伴うため、発信には人間の判断が必要である。
- 初版では社内報告と外部報告が同じフローに入っており、社内報告が外部報告の判定に左右されていた。

## 検討した代替案

| 案 | 採らなかった理由 |
|---|---|
| 判定・発信とも人間が行う | 判定が遅れ、期限に間に合わないおそれがある |
| 判定・発信とも自動 | 誤った通報の危険が大きい |
| グループCISOが判定・承認する | 法人ごとの報告義務と合わない(ADR-004) |

## 変更するときの影響範囲

- 判定ルールを変える場合: [GOV-003](../../01-governance/01-03-external-reporting-flow.md) 第3章(法務部門と協議)
- AIに送信まで任せる場合(非推奨): [AI-002](../../02-agentic-ai/02-02-authority-levels.md) 第4章、[AI-001](../../02-agentic-ai/02-01-architecture.md) の報告ドラフト・エージェントの権限
