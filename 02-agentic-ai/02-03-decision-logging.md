# 判断ログの要件

AIの判定と実行を、後から人間が検証できるように記録する。記録する項目(フォーマット)は
[REC-002](../05-records-kpi/05-02-ai-decision-log-format.md) に定める。本文書は記録の要件を定める。

## 1. 記録の対象

- エージェントによるすべての判定(一次評価、権限レベルの判定、外部報告の要否判定など)
- すべての措置の実行・失敗・取り消し
- 人間による確認・承認・却下、措置の継続・解除の判断
- Kill-switchの発動と解除
- 証拠パッケージの作成と版の追加、引用検証の結果([AI-006](02-06-evidence-grounded-investigation.md))

## 2. 要件

| 要件 | 内容 |
|---|---|
| 説明可能性 | 判定根拠を自然言語で残す。根拠は証拠パッケージの項目IDの引用で示す([AI-006](02-06-evidence-grounded-investigation.md)) |
| 検証可能性 | 証拠パッケージのIDと版、引用検証の結果、除去・訂正した所見、カバレッジギャップを残す。判定を後から同じ証拠で検証できるようにする |
| 判定信頼度 | エージェントが出力した信頼度を参考値として残す(異常検知に使うため。[AI-004](02-04-audit-and-kill-switch.md))。判定区分の代わりにはしない |
| 再現性 | 判定時のエージェント名・モデル名・バージョン、適用した規則(除外条件・保護資産リスト・判定語彙・Runbook)の版を残す |
| 改ざん防止 | 判断ログと証拠パッケージを追記専用の領域に保存し、AIエージェントには変更・削除の権限を与えない |
| 保存期間 | 5年 `P-19` |
| 連携 | 判断ログをSIEMに取り込み、インシデント記録([REC-001](../05-records-kpi/05-01-incident-record-format.md))から参照できるようにする |

## 3. 個人情報の扱い

判断ログと証拠パッケージには、アカウント名や通信内容などの個人情報が含まれる。参照できる人をSOC・CSIRTの要員と
監査担当に限る。内部不正に関するログは、さらに対象を絞る([SOC-005](../03-soc-runbooks/03-05-insider-threat.md))。
