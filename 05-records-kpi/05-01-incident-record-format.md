# インシデント記録フォーマット

インシデント1件につき1件の記録を作る。実際の運用では、チケット管理システムやSIEMのインシデント
管理機能にこの項目を移して使う。各Runbook・Playbookが定めるシナリオ固有の項目は「シナリオ固有」欄に追記する。

- 必須: すべての記録で入力する
- 誤検知時も必須: 誤検知としてクローズした場合も入力する(誤検知率の算出に使う)
- 該当時: 条件に当てはまる場合に入力する

## 1. 基本情報

| 項目 | 内容 | 入力 |
|---|---|---|
| インシデントID | 一意の識別子(例: `INC-2026-0001`) | 誤検知時も必須 |
| 検知元アラートID | SIEMのアラートID | 誤検知時も必須 |
| 判定結果 | 誤検知 / 真陽性。人間が確定する。軽量トリアージでクローズした件はAIの判定のまま記録し、日次サンプリングで確認する([AI-004](../02-agentic-ai/02-04-audit-and-kill-switch.md)) | 誤検知時も必須 |
| AIの判定区分 | [AI-006](../02-agentic-ai/02-06-evidence-grounded-investigation.md) 第6章の判定区分(人間の確定と異なる場合も、AIの出力のまま残す) | 該当時 |
| 対象の構成会社 | 構成会社名 | 必須 |
| 対象アセット | ホスト名・アカウント・クラウドリソースなど | 必須 |
| 適用したRunbook・Playbook | 文書ID(例: `SOC-002`、`CSIRT-012`) | 必須 |

## 2. 時刻

| 項目 | 内容 | 入力 |
|---|---|---|
| 推定発生時刻 | 調査で判明した攻撃の開始時刻(ISO 8601)。不明な場合は「不明」 | 必須 |
| 検知時刻 | アラートの発生時刻 | 誤検知時も必須 |
| 初動時刻 | 封じ込めの開始、または担当者の対応開始の時刻([GOV-002](../01-governance/01-02-severity-matrix.md) 第2章) | 必須 |
| クローズ時刻 | 対応の完了時刻 | 誤検知時も必須 |

## 3. 重大度

| 項目 | 内容 | 入力 |
|---|---|---|
| 影響度・緊急度 | 大/中/小、高/中/低([GOV-002](../01-governance/01-02-severity-matrix.md)) | 必須 |
| 重大度 | Critical / High / Medium / Low | 必須 |
| 適用した補正 | Runbookの重大度補正のうち適用したもの | 該当時 |
| 重大度の変更履歴 | 変更日時、変更前後、変更した人、理由 | 該当時 |
| 初動対応時間目標の超過 | 超過の有無と理由 | 該当時 |

## 4. 対応

| 項目 | 内容 | 入力 |
|---|---|---|
| 対応したTier | Tier1 / Tier2 / Tier3 / CSIRT | 必須 |
| 時間帯 | 有人時間帯 / 夜間・休日([GOV-005](../01-governance/01-05-operating-hours.md)) | 必須 |
| AIの判断ログID | [REC-002](05-02-ai-decision-log-format.md) のログID(複数可) | 該当時 |
| 証拠パッケージID | [AI-006](../02-agentic-ai/02-06-evidence-grounded-investigation.md) の証拠パッケージのIDと版(複数可) | 該当時 |
| 未確認の証拠 | カバレッジギャップのうち、クローズ時点でも未確認だった項目と理由 | 該当時 |
| CSIRT発動 | 発動日時、インシデントマネージャー | 該当時 |
| 社内報告 | グループCISOへの報告日時 | 該当時 |
| 実施した措置 | 隔離・遮断などの措置と、継続・解除の判断 | 該当時 |

## 5. 外部報告([GOV-003](../01-governance/01-03-external-reporting-flow.md))

| 項目 | 内容 | 入力 |
|---|---|---|
| 判定結果 | 不要 / 必要 / 判定中 | 必須(High以上) |
| 判定日時・根拠 | 判定ルールのどの基準に該当したか | 該当時 |
| 報告主体 | 報告する構成会社 | 該当時 |
| 承認者・承認日時 | 構成会社責任者 | 該当時 |
| 報告先・報告日時 | 速報・確報それぞれの報告先と日時 | 該当時 |

## 6. 事後

| 項目 | 内容 | 入力 |
|---|---|---|
| 事後レビュー | 実施日と記録へのリンク([CSIRT-003](../04-csirt-playbooks/04-03-post-incident-review.md)) | Critical・Highは必須 |
| 再発防止策 | 作業の一覧へのリンク | 該当時 |
| シナリオ固有 | 各Runbook・Playbookの「記録」に定める項目 | 該当時 |
