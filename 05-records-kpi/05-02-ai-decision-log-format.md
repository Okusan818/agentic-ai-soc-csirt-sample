# AI判断ログフォーマット

[AI判断ログ(説明可能性)(AI-003)](../02-agentic-ai/02-03-decision-logging.md)で定義した項目を、
実記入用のテンプレートとして確定する。

## 記録テンプレート

| 項目 | 内容 |
|---|---|
| ログID | 一意の識別子(例: `AILOG-2026-00001`) |
| 判定時刻 | ISO 8601形式 |
| 対象アセット | ホスト名・アカウント・IPなど |
| トリガー | 元となったアラートIDまたは入力データ |
| 実行エージェント | エージェント名・使用モデル |
| 判定根拠 | 自然言語による要約(なぜその対応を選んだか) |
| 権限レベル | Lv1(自動実行) / Lv2(事後承認) / Lv3(事前承認) |
| 実行結果 | 成功 / 失敗 / ロールバック |
| レビュー結果 | レビュー者・判定(妥当/要修正)・コメント |
| 関連インシデントID | [インシデント記録(REC-001)](05-01-incident-record-format.md)のID(発生している場合) |
