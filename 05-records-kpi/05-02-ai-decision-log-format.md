# AI判断ログフォーマット

AIの判定・措置1件につき1件の記録を作る。記録の要件(改ざん防止、保存期間など)は
[AI-003](../02-agentic-ai/02-03-decision-logging.md) を参照。

| 項目 | 内容 | 入力 |
|---|---|---|
| ログID | 一意の識別子(例: `AILOG-2026-00001`) | 必須 |
| 判定時刻 | ISO 8601 | 必須 |
| 時間帯 | 有人時間帯 / 夜間・休日 | 必須 |
| 実行エージェント | エージェント名、モデル名とバージョン | 必須 |
| 判定の種類 | 一次評価 / 措置 / 外部報告の要否判定 / その他 | 必須 |
| トリガー | 元になったアラートID、または入力データへの参照 | 必須 |
| 対象 | ホスト名・アカウント・リソース・IoC | 必須 |
| 対象数 | [AI-002](../02-agentic-ai/02-02-authority-levels.md) の数え方による対象数 | 措置の場合は必須 |
| 判定根拠 | なぜその判定・措置を選んだかの説明 | 必須 |
| 判定信頼度 | エージェントが出力した信頼度 | 必須 |
| 権限レベル | Lv1 / Lv2 / Lv3 / 実行しない操作 | 措置の場合は必須 |
| Kill-switchの状態 | 有効 / 無効 | 必須 |
| 承認者・承認日時 | Lv3の承認者、Lv2の確認者 | 該当時 |
| 実行結果 | 成功 / 失敗 / 取り消し | 措置の場合は必須 |
| 継続判断 | 継続 / 解除 / 期限切れ、判断した人と日時([AI-002](../02-agentic-ai/02-02-authority-levels.md) 第6章) | Lv1・Lv2の措置は必須 |
| 異常検知 | 異常検知アラートの対象になったか | 必須 |
| レビュー結果 | レビューした人、判定(妥当 / 要修正)、コメント | サンプリング対象・Lv2は必須 |
| インシデントID | [REC-001](05-01-incident-record-format.md) のID | 該当時 |
