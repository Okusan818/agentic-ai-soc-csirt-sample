# 事後レビュー(ポストモーテム)フォーマット

## 1. 実施タイミング・参加者

- **実施タイミング**: インシデント収束後、原則1週間以内
- **参加者**: インシデントマネージャー、対応にあたった各Tierアナリスト、必要に応じてCISO・
  構成会社PoC

## 2. 記載項目

| 項目 | 内容 |
|---|---|
| インシデント概要 | 発生日時、重大度([GOV-002](../01-governance/01-02-severity-and-escalation.md)の分類)、影響範囲 |
| タイムライン | 検知〜収束までの主要なイベントと対応時刻 |
| 根本原因 | 侵害経路・脆弱性・設定ミス等の特定結果 |
| 良かった点 | 対応が効果的だった点(Agentic AIの自動対応が有効だった場合はその内容も含む) |
| 改善点 | 対応の遅延・判断ミス・ツールの不足等 |
| 再発防止アクション | 担当者・期限を明記したアクション一覧 |

## 3. 原則

- 個人の非難を目的とせず、プロセス・仕組みの改善に焦点を当てる(blameless postmortem)。
- 再発防止アクションは、[記録フォーマット・KPI(05-records-kpi/)](../05-records-kpi/)で
  進捗を追跡する。
